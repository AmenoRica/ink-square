# Ink Voice Lab

브라우저 마이크 입력을 먼저 RNNoise 전용 잡음 억제기로 정리한 다음, 고전 DSP로 유성음의 음높이·세기·발화 타이밍만 추출합니다. 실제 자음과 모음은 전달하지 않고 eSpeak NG로 미리 합성한 캐릭터 음절을 재조합한 뒤, City of Color 보컬로 학습한 작은 잔차 필터로 질감만 다듬는 로컬 음성 변조 프로토타입입니다. 음성은 서버로 전송하지 않습니다.

기본 프리셋은 빠른 음절 전개와 2단 저역 필터를 사용해 매끄럽고 먹먹한 수중 음색을 냅니다.
입력 한 음절마다 eSpeak NG 음절 하나를 생성합니다. 짧은 무성 구간은 앞 모음을 최대 140ms 유지하고, 새 음절이 감지되면 기다리지 않고 64ms 교차 연결해 한 구절처럼 이어집니다. 출력 강약은 압축 전 원본 발화 에너지를 따라갑니다.
각 생성 발음은 최소 160ms 유지하고 음절 감지 사이도 120ms 더 이어 재생합니다. 화면의 `음높이 낮음/보통/높음` 버튼은 각각 +12/+15/+18 반음이며 기본값은 보통입니다.
`날카로움/기본/부드러움` 버튼은 각각 자음이 선명한 5.2kHz 출력, 물을 머금은 3.2kHz 출력, 둥글고 길게 이어지는 2.3kHz 출력을 선택합니다. 날카로움에서는 가사 뱅크의 `시/슈/샤/씨/차/체/쵸/쥬` 계열을 추가로 선택하고, 이 초성들이 모음으로 약화되는 비율을 낮춥니다.
`신남 ON`은 말의 속도나 음높이를 바꾸지 않고 각 생성 음절의 첫 55ms에 최대 12%의 짧은 강세만 더합니다.
각 음절 뱅크에는 원래 음높이와 파형 주기에 맞춘 모음 루프 지점이 들어 있습니다. 한 모음을 길게 유지하면 새 음절을 반복 생성하지 않고 같은 음절의 모음 주기만 이어서 재생하며, 입력이 끝날 때 받침과 짧은 감쇠로 빠져나옵니다. 재생 속도 대신 원본·목표 음높이의 비율을 사용해 음높이와 지속 시간을 따로 제어합니다.
입력과 생성 음절은 확장 없이 정확히 1:1로 대응합니다. 기본과 부드러움 스타일에서는 강한 파열·마찰 초성의 15%만 모음 시작 발음으로 약화합니다.
선택한 구절은 순서대로 진행하며, 직전 음절 반복은 3%, 다른 구절의 음절로 바뀌는 전환은 6%만 적용합니다.
합성 피치는 원래 억양을 거의 연속적으로 따라가며 반음 스냅은 아주 약하게만 섞습니다. 음절 사이를 길게 교차 연결하고 앞뒤 세기 차이를 줄여 부드럽게 이어집니다. 출력에는 3.2kHz 저역 통과와 680Hz의 완만한 입안 공명을 적용해, 버블음을 늘리지 않고 입안에 물을 머금은 듯한 먹먹함을 만듭니다. 겹쳐 들리는 유니즌은 사용하지 않습니다.
발음 팔레트는 단모음 외에 `ya/yo/yu/wa/we/wi/wo/ae/eo/ui` 활음, 서로 다른 비음·탄설음·마찰음·파열음과 7계열 종성을 구분해 합성합니다.
종성은 `-n/-m/-l/-t/-k/-p/-ng` 7계열이 기본 설정에서 약 37% 확률로 붙습니다. `~` 토큰은 보통 음절의 2.15~3배 길게 유지하며, `앓씌잇~`, `우미~`, `조아따~`, `개추다~`에 대응하는 구절도 생성 목록에 포함됩니다.
초성은 짧은 덧소리가 아니라 40~70ms의 독립 발음 구간으로 생성합니다. 이 구간의 약 70%는 모음 공명을 완전히 닫고 자음 파열·마찰 자체를 강하게 낸 뒤 모음으로 전환합니다. 음높이 검출은 가벼운 2단계 탐색을 사용해 실시간 처리 지연으로 생기는 지직거림을 줄입니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 Chrome 또는 Safari에서 열고 **마이크 시작**을 누른 뒤 권한을 허용합니다. 스피커와 마이크 사이의 하울링을 피하려면 헤드폰을 사용하세요. 마이크는 브라우저 정책상 `localhost` 또는 HTTPS에서만 사용할 수 있습니다.

완성본 확인:

```bash
npm run build
```

## 구조

- `app/page.tsx`: 사용자 화면과 조작 상태
- `lib/audio/inkling-engine.ts`: 마이크, 오디오 그래프, WAV 녹음, 출력 스트림
- `@sapphi-red/web-noise-suppressor`: RNNoise WASM과 AudioWorklet을 이용한 입력 잡음 억제
- `public/espeak-bank.json`: eSpeak NG가 미리 합성한 74종 음절 PCM과 피치 동기 루프 정보
- `public/city-postfilter.json`: City of Color 분리 보컬에서 학습한 153개 매개변수의 인과형 잔차 필터
- `public/inkling-processor.js`: 음높이·발화 타이밍을 추적하고 음절 뱅크를 재배열·재생하는 AudioWorklet DSP
- `scripts/build-espeak-bank.mjs`: 음절 뱅크와 피치 동기 루프 재생성 도구
- `scripts/train-city-postfilter.py`: 분리된 보컬 WAV로 작은 후처리 필터를 다시 학습하는 도구

맨 앞단의 RNNoise는 가벼운 신경망으로 생활소음과 타건음을 억제하며 WASM AudioWorklet에서 로컬 실행됩니다. 서버나 API 키는 필요 없습니다. RNNoise를 불러오지 못하면 브라우저 내장 잡음 억제로 자동 전환합니다. 그 뒤의 음높이 신뢰도와 유성음 유지 판정도 비주기성 충격음이 캐릭터 음절을 잘못 생성하지 않도록 한 번 더 거릅니다. 다만 말소리와 동시에 아주 가깝고 크게 녹음된 타건음은 완전히 없어지지 않을 수 있습니다. 캐릭터 AudioWorklet이나 필수 음성 자료를 불러오지 못하면 원음이 전송되지 않도록 음성 연결을 중단합니다. 녹음은 브라우저별 MediaRecorder 형식 차이를 피하기 위해 모노 WAV로 저장합니다.

음절 뱅크는 GPL-3.0-or-later인 [eSpeak NG](https://github.com/espeak-ng/espeak-ng)의 출력으로 만들며, `npm run build:voice-bank`로 다시 생성할 수 있습니다.

## 온라인 연결

Supabase Realtime의 `ingscord:v1` Presence/Broadcast 채널은 접속자 목록과 WebRTC 연결 협상에만 사용합니다. 채팅과 변조된 음성은 피어끼리 직접 전송하며 서버와 데이터베이스에는 저장하지 않습니다.

로컬 실행에는 `VITE_SUPABASE_URL`과 `VITE_SUPABASE_PUBLISHABLE_KEY`가 필요합니다. GitHub Pages 배포는 `.github/workflows/deploy-pages.yml`에서 같은 공개 설정을 빌드에 주입합니다.
